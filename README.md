# LJT-Homepage

This is the repository for Junteng Liu's academic personal homepage, built with the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) (a [Jekyll](https://jekyllrb.com/) theme hosted by [GitHub Pages](https://pages.github.com/)).

## Contents

- **About** (`_pages/about.md`): personal details, academic background, research experience, publications, skills, and contact information.
- **Publications** (`_pages/publications.html` + `_publications/`): the list of publications.

## Local development

Install the prerequisites (Ruby, RubyGems, gcc, make), then:

```bash
bundle install
bundle exec jekyll serve
```

The site will be available at `http://localhost:4000/LJT-Homepage/`.
